## Objective

Initialize the TradePilot frontend project and establish the basic application structure.

## Task

1. Inspect the existing repository.
2. Initialize a modern frontend project suitable for deployment on Vercel.
3. Create the basic application shell.
4. Create placeholder routes/pages for:
   - Home
   - Analysis Input
   - AI Analysis Loading
   - Market Report
5. Add a simple global layout and navigation structure.
6. Ensure the application runs locally without errors.

## Important

Do not build the final UI yet.

Do not add:

- APIs
- databases
- authentication
- external AI services
- backend services

The goal of this task is only to establish a clean working project foundation.

## Definition of Done

The task is complete when:

- the project runs locally
- all four routes exist
- navigation between routes works
- there are no blocking runtime errors
- the repository structure is clean
- the project is ready for Home page development

## After Completion

Update `CHANGELOG.md`.

Then stop and wait for the next task.
