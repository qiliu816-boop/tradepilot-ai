# tradepilot-ai
AI-powered cross-border market research assistant for evidence-backed market opportunity analysis.

## Run locally

Requires Node.js and pnpm.

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Vite. The placeholder routes are `/`, `/analysis`, `/loading`, and `/report`.

Run `pnpm build` to check the production build. The Vercel rewrite serves the app shell for direct route visits.
